# 3D icons

Rendered 3D icons used across the marketing site.

- **Source:** [3dicons](https://3dicons.co) by realvjy — https://github.com/realvjy/3dicons
- **Licence:** CC0 1.0 Universal (public domain dedication). Free for commercial
  use, no attribution required. Verified against the repository's own `LICENSE`
  file, which is `CC0-1.0`.
- **Style:** `premium` — charcoal body with gold hardware. Chosen over `color`
  (orange/red) and `gradient` (purple/orange), both of which fight the forest
  green brand. This one shares the ink-and-gold palette the marketing site
  already uses.
- **Variant:** `dynamic` camera angle, 400x400 PNG with transparency.
- **Fetched:** 2026-09-02

## Re-fetching or adding an icon

The CDN pattern is:

    https://3dicons.sgp1.cdn.digitaloceanspaces.com/v1/{angle}/{style}/{slug}-{angle}-{style}.png

The full list of the 120 available slugs lives in the source repo under
`content/3dicons-meta/`. Each `.md` there also carries the URLs for that icon's
four styles.

Attribution is not required by CC0, but the provenance is recorded here so a
future maintainer can find more icons in the same set rather than mixing in a
second one — a page with two different 3D styles on it looks like a mistake.
